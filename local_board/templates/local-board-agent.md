# Local Board agent policy

This repository uses Local Board as the operational source of truth.

Before changing code, use the configured Local Board MCP server to identify yourself, find or create the issue, read its full context, and claim it. Keep checklist, comments, dependencies, Git links, reviewer, and workflow status current. Use stable issue identifiers in branches and handoffs. Never access `.local-board/state/board.db` directly and never commit or disclose bearer tokens.

If the Local Board tools are unavailable, run `local-board doctor` or report the connectivity problem instead of maintaining a parallel task list.
