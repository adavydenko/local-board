## Bootstrap and operational observations

Successful bootstrap required CLI help discovery, `init`, CLI actor creation, manual one-time token capture, foreground `serve`, environment export, MCP `initialize`, `tools/list`, `whoami`, and online doctor. Doctor passed config, policy, skill, schema, integrity, foreign keys, drift, initialization, and all 38 advertised tools.

Observed friction:

1. The first online doctor correctly failed because no token was supplied.
2. An initial operator export used `TOKEN` instead of `LOCAL_BOARD_TOKEN`; doctor made the correction discoverable.
3. Two MCP requests failed with HTTP 406 until `Accept: application/json, text/event-stream` was used. This transport requirement was not obvious from generated onboarding.
4. `init` created `.local-board/AGENT.md` and the repository skill but no root `AGENTS.md`, leaving generic harness discovery incomplete.
5. Actor provisioning, token rotation/revocation, and scoped credentials were unavailable through MCP.
6. Checklist mutations did not increment issue revision, so revision did not version the complete aggregate context.
7. Local Board shutdown by Ctrl-C printed a `KeyboardInterrupt` traceback and returned exit code 1.
8. MCP `serverInfo.version` reported `0.1.0` although the installed distribution version was `0.0.1`.

## Credential observations

The generated token was not committed, added to board content, or left in tracked files. It was captured in a mode-0600 ignored file, and a tracked-file secret scan was empty.

There was nevertheless a real exposure near-miss: CLI printed the raw token to stdout, and an attempted redaction expected a different output shape, so the credential entered the terminal/tool transcript. Safe setup required manual redirection, restrictive permissions, extraction, environment export, and ignore configuration.

`python -m unittest discover -s tests -v` passed 2/2 store and HTTP/UI tests in 0.544 seconds. The app was also started on port 8099; real POST and GET requests created and returned a focus task. The app shut down cleanly with exit code 0.
